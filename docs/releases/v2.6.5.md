本版本可提取插件运行时由静态名称字典和状态列表组合生成的有限 UI 标签。例如，ClothingStateMenu 的 `Bra: On`、`Underwear: Off` 和 `Legwear: On` 现在会出现在常规文本列表中。

使用包含本修复的本地构建版重新扫描了 303 个插件 DLL，在 `AllStrings.txt` 和按插件结果中均找到 32 条服装类型/状态组合文本。

此更新仅改进静态文本提取，不会修改插件或注入翻译。源 DLL 中的状态拼写为大写 `Off`。

**English**

v2.6.5 extracts finite UI labels assembled at runtime from a static label dictionary and a static state list. ClothingStateMenu labels such as `Bra: On`, `Underwear: Off`, and `Legwear: On` now appear in the normal string lists.

The locally built version containing this fix was used to scan 303 plug-in DLLs. It recovered 32 clothing-kind/state combinations in both `AllStrings.txt` and the per-plugin output.

This update changes static extraction only. It does not modify plug-ins or inject translations. The source DLL capitalizes the state label as `Off`.
