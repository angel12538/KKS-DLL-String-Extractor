本版本修复多行设置说明在主要 TXT 中看起来像漏提取的问题。例如，插件中包含多段换行的说明，旧版主要列表只显示 `[SPECIAL:编号]`，完整文字需要到特殊存档中查找。

**本次更新**

- 在 `AllStrings.txt`、翻译候选表、UI 表和按插件导出的 TXT 中，直接显示特殊字符串的完整 `// preview=` 原文预览。
- 真实换行显示为 `\n` / `\r`，便于搜索和阅读；精确原文仍完整保存在 `SpecialStrings_Exact.txt` 和 `ByPlugin_Special/` 中。
- 保留普通 `原文=` 条目、原文去重方式、特殊字符串编号及 UI 分类结果。
- 新增多行配置说明回归测试，覆盖四种主要列表和两种按插件列表。
- 修复 GitHub Actions 发布工作流中重复定义 `push` 导致的解析失败。

**下载与使用**

- Windows x64：下载并完整解压 `KKS-DLL-String-Extractor-win-x64.zip`，双击 `KKS_DLL_String_Extractor.exe`，按中文提示选择插件目录。
- Linux x64：下载并解压 `KKS-DLL-String-Extractor-linux-x64.zip`，执行 `chmod +x KKS_DLL_String_Extractor` 后运行。
- 两个平台均为自包含发布，无需单独安装 .NET Runtime。分发时请保留许可证及 `licenses/` 文件夹。

**验证**

Windows 和 Linux 发布包均通过内置自测。本地使用 303 个 DLL 验证了原文预览；与修复前相比，普通条目和精确存档均保留，仅跳过 1 个不属于托管扫描范围的原生辅助 DLL。

`// preview=` 是阅读注释，不是可直接填写的翻译键。游戏内翻译仍应以 XUnity.AutoTranslator 实际捕获的原文为准。

**English**

Multiline configuration descriptions now show complete searchable previews in the main and per-plugin TXT lists instead of appearing only as special-string IDs. Exact archives, ordinary keys, deduplication and classification are preserved. This release also fixes the duplicate `push` event definition in the release workflow and adds regression coverage for multiline descriptions. Self-contained Windows x64 and Linux x64 packages are included.
