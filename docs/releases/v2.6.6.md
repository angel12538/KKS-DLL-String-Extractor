修复内嵌 Unity 资源中的文本漏提取问题。人物编辑页面中 LewdCrestX 的生育能力说明（以 `Makes her always able to become pregnant` 开头）和 `[+] Violove` 现在可以在 `AllStrings.txt` 及按插件输出中找到。

- 支持读取 DLL 内嵌 UnityFS 资源包中的 TextAsset，支持未压缩、LZ4 和 LZ4HC，资源文件名无需带特定扩展名。
- 提取 XML 解码后的文本值，并根据可静态确认的字段映射和枚举集合还原条件前缀标签。
- 按需读取压缩块，限制读取范围及资源大小；禁止 XML DTD 和外部实体，并增加相应回归自检。

包含此修复的本地构建已重新扫描 303 个插件 DLL，确认上述说明和标签被提取，`Bra: On`、`Underwear: Off` 等服装状态文本仍然保留。

当前不支持 LZMA 压缩的 UnityFS 资源包；这些资源及其他不支持的布局会记录在 `Errors.txt`。本次确认的目标文本来自 `KKS_LewdCrestX.dll`。

提供 Windows x64 和 Linux x64 独立运行压缩包，无需另行安装 .NET。

**English**

v2.6.6 extracts TextAssets from embedded UnityFS bundles using uncompressed, LZ4, or LZ4HC blocks. It exports decoded XML leaf values and conservatively reconstructs conditional labels from statically verified field mappings and enum sets.

The character-editor description beginning `Makes her always able to become pregnant` and the `[+] Violove` label in LewdCrestX now appear in the normal string exports. A local scan of 303 plug-in DLLs confirmed these strings and retained the existing clothing-state labels.

Bundle reads are bounded and performed on demand. XML DTDs and external entities are disabled. Generated regression fixtures cover bundle parsing, malformed ranges, XML decoding, and conditional labels. LZMA-compressed bundles remain unsupported and are reported in `Errors.txt`.
